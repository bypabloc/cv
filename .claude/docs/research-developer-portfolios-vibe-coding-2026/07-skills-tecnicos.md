# Skills Tecnicos Hot 2025-2026

## Lenguajes: Demanda vs Compensacion

| Lenguaje | Demanda | Sueldo | Razon |
|----------|---------|--------|-------|
| **TypeScript** | +250% (ahora #1 en GitHub) | $110K-$180K +10-15% premium | Dominante en frontend, full-stack |
| **Python** | +150% | $120K-$200K | AI/ML, data science, backend |
| **Rust** | +35% YoY | $130K-$235K (+15-20% premium) | Escasez de talento, systems work |
| **Go** | +20% YoY | $120K-$180K | 3-4x mas jobs que Rust, cloud-native |
| **Java** | Estable | $130K-$220K | Enterprise, pero requiere 5+ años exp |

## AI/ML Skills Now Expected

**NO necesitas ser investigador, pero:**

1. **RAG + Embeddings**: Como indexar documentos, vector stores (Pinecone, Supabase pgvector)
2. **Agent Frameworks**: LangChain, LlamaIndex, CrewAI—orquestacion, no entrenamiento
3. **Prompt Engineering**: Tecnicas (few-shot, chain-of-thought), evaluacion de hallucinations
4. **Fine-tuning Basics**: Cuando, por que, como (OpenAI, Replicate)
5. **LLM Integration**: APIs (OpenAI, Anthropic, open-source via Ollama)

**Portfolio evidence:**
- 1-2 proyectos con RAG visible ("Built Q&A chatbot on 500 legal docs")
- Blog post sobre "How we detect hallucinations in [domain]"
- GitHub repo con agent workflow documentado

## Full-Stack 2026 (Especializacion vs Generalisimo)

**Cambio clave:** El debate "full-stack vs especialista" esta RESUELTO: **full-stack thinking, potencial especialista**.

**Significa:**
- Entender ambos lados = mejores decisiones arquitectonicas
- Se profundo en UNO, competente en los demas
- Ejemplo: "React expert que puede debuggear PostgreSQL queries y CI/CD"

**Skills minimos esperados (2026):**

```
Frontend: React/Vue/Svelte + TypeScript + TailwindCSS + testing library
Backend: Node.js/Python/Go + database (SQL) + auth + API design
DevOps: Docker, GitHub Actions, 1 cloud (AWS/GCP/Vercel/Fly.io)
AI: RAG + prompt engineering + LLM API integration
```

## Skills Obsoletos (¡STOP contando!)

- jQuery, Flash, Objective-C alone, CoffeeScript
- "Experto en 10 frameworks" (pick 3 max)
- Certifications genericas (AWS Solutions Architect, etc.) sin demostracion real
