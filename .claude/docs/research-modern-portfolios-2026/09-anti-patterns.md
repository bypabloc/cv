# Anti-Patterns y Errores Comunes

## Top 10 Errores en Portfolios 2025-2026

| Error | Consecuencia | Solucion |
|---------|---------|---------|
| **Sin Case Studies** | Parece resumen de CV | Incluir 3-5 projectos con Problema -> Solucion -> Impacto |
| **Solo output, sin proceso** | No demuestra pensamiento critico | Mostrar sketches, decisiones, tradeoffs |
| **Proyectos muy viejos** | Parece estancado/abandonado | Actualizar "Portfolio actualizado May 2026" |
| **Sin numeros/metricas** | Descripciones genericas | Siempre: 40% latency reduction, 100K+ users |
| **No indexable por ATS** | Reclutadores no pueden parsearlo | Formato single-column, sin tablas/imagenes |
| **No accessible (WCAG)** | Excluye usuarios con discapacidades | 4.5:1 contrast, semantic HTML, alt text |
| **Performance malo** | Bounce rate alto, malas rankings | Target 100/100 Lighthouse, LCP < 2s |
| **Sin dark mode** | 80%+ usuarios esperan dark mode | Implementar next-themes o CSS variables |
| **Links rotos a demos/repos** | Deshonra profesional | Verificar quarterly links funcionen |
| **Lenguaje vago sin link a codigo** | "Experto en X" sin prueba | Siempre: GitHub repo o live demo |
