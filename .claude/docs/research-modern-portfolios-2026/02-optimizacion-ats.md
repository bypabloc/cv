# Optimizacion para ATS

## El Panorama ATS 2025-2026

**Datos clave:**
- 99.7% de reclutadores usan filtros en ATS o sistemas similares
- Candidatos que incluyen el job title tienen **10.6x mas probabilidad** de entrevista
- **Adoption de IA en ATS paso de 26% (2024) a 43% (2025)**
- Mercado global ATS: $3.28B en 2025, creciendo 8.2% CAGR hasta 2030

## Evolucion ATS: De Keywords a Contexto

**2024 y antes:**
- Parsing simple de palabras clave
- Matching literal contra job description
- Falsos positivos/negativos frecuentes

**2025-2026:**
- **Contextual understanding**: Comprension semantica del CV vs. descripcion
- **Identificacion de candidatos calificados pero no obvios**
- Analisis de patrones de experiencia (no solo palabras)
- Reduccion de sesgos mediante analisis estructurado

## Como Optimizar tu CV para ATS 2025-2026

### 1. Formato Critico

**Recomendacion**: Single-column layout, sin tablas, texto boxes, headers/footers con contenido critico

| Evita | Recomendado |
|---------|---------|
| Tablas anidadas | Layout lineal top-to-bottom |
| Imagenes/graficos | Badges textuales |
| Multiples columnas | Single column |
| Headers y footers | Contenido en body |
| Colores decorativos | Texto legible (blanco/negro) |

### 2. Ubicacion Estrategica de Keywords

El **job title es el keyword mas importante**. Ubicacion recomendada:

```
[TU NOMBRE]
Senior Full-Stack Developer  ← Job title VISIBLE, idealmente en resumen profesional

PERFIL PROFESIONAL
Desarrollador Senior con 7+ anos en Full-Stack, especializacion en Python/Django
y React. Experiencia en arquitectura de microservicios, lideranza de equipos.
[INCLUYE JOB TITLE DE NUEVO AQUI, 2-3 veces distribuido naturalmente]
```

**Regla**: Incluye el job title 2-3 veces en el CV, prioritizando header y perfil profesional.

### 3. Keywords por Contexto

| Seccion | Contenido | Ejemplo |
|---------|----------|---------|
| **Habilidades tecnicas** | Hard skills, herramientas, certs exactamente como aparecen en job posting | Python 3.14, Django 6, PostgreSQL 18, Docker, Pytest |
| **Experiencia** | Verbos de accion + contexto cuantificable | Disene arquitectura de microservicios que redujo latencia 40%, impactando 2M+ usuarios |
| **Palabras que se repiten** | Identifica terminos que aparecen 2+ veces en job posting | Si dice "TypeScript" x3, copialo literalmente |

### 4. Errores que Descartan Automaticamente

Estos errores causan rechazo automatico en ATS 2025-2026:

1. **Desalineacion job title**: CV dice "Desarrollador Web", posting pide "Full-Stack Engineer"
2. **Fecha de graduacion incompatible**: Si piden 5 anos y tu experiencia no lo refleja
3. **Hard skills faltantes**: Si la seccion de skills no tiene 3+ herramientas claves del posting
4. **Formato ilegible por ATS**: Tablas, imagenes, PDFs con fuentes embebidas
5. **Experiencia reciente < 2 anos**: Gaps grandes sin explicacion
6. **Falta de numeros/metricas**: Todo es descripcion, sin impacto cuantificable

### 5. Herramientas para Validar Compatibilidad ATS

- **Jobscan** (jobscan.co): Compara tu CV contra job posting especifico, da score ATS
- **SkillSyncer** (skillsyncer.com): Free ATS scanner
- **Varios AI resume builders**: Enhancv, Kickresume (incluyen ATS optimization)

## Recomendacion para CV + Portfolio Web

**NO** presentes SOLO portfolio web a reclutadores. El workflow es:

1. CV optimizado para ATS (PDF o DOCX compatible)
2. Link al portfolio web en CV
3. GitHub con repos bien documentados (README detallado)
4. LinkedIn con resumen del portfolio
