# Presencia Online: Twitter, LinkedIn, Dev.to, Twitch

## Platform Hierarchy by ROI (2025-2026)

```
TIER 1 (HIGHEST ROI for developers)
├─ Twitter/X: Technical audience 4x larger than LinkedIn
│  └─ Dev community accessible, less gatekeeping
│  └─ Code snippets & threads get 3-5x more engagement
│
├─ GitHub: Your portfolio (50% of signal)
│  └─ Activity, consistency, quality of work
│
└─ Personal Blog: Deep expertise documentation
   └─ SEO value + authority (E-E-A-T signals)

TIER 2 (Supporting)
├─ LinkedIn: Professional network + recruiters
│  └─ Vertical video & live streams get 12-24x more reach (2025 algo update)
│
├─ Dev.to: Developer community + syndication hub
│  └─ 1-2 deep posts/month can drive 500+ qualified visitors
│
└─ YouTube/Twitch: Live coding showcase
   └─ Underutilized but high-impact if consistent

TIER 3 (Optional)
├─ Hashnode: Blog platform
├─ Medium: Reach pero less discovery
└─ Discord: Community building (not visibility)
```

## Twitter/X Strategy (2025-2026)

**Que funciona:**

1. **"Learning in public" threads**
   - "Building [X] today: here's what I learned about [tech]"
   - 50-100 likes = opportunity for VC, job offers, partnerships
   
2. **Code snippets comentados** (visual + educational)
   - GIF de live coding, commit message legible
   - 200-500 likes tipicos si es util

3. **Technical decisions explained**
   - "Switched from Postgres to DuckDB for analytics, 30s → 2ms latency"
   - Especifico, metrica, "why" visible

EVITAR:
- Memes sin sustancia
- Complaints sobre bugs ajenos
- "Rant" sin propuesta

## LinkedIn (2025-2026 Algorithm Update)

**Cambios clave:**
- Contenido vertical (video) ahora preferido
- Native video alcanza 12-24x vs texto
- Posts con engagement alto distribuidos durante MESES (no dias)

**Que publicar:**
- Live streams explicando arquitectura
- Behind-the-scenes de proyectos
- "What I learned shipping X" posts (profesionales, no guru-bait)
- Insights sobre IA en hiring / desarrollo

## Dev.to Strategy

**Modelo 2025:**
1. Escribir articulo tecnico profundo (1,500-3,000 palabras)
2. Publicar en tu blog primero (SEO tuyo)
3. Sindicalizar a Dev.to (1-2 semanas despues)
4. Enlazar desde Twitter/LinkedIn

**ROI:** 1 articulo bien hecho = 500-2,000 visits calificados + 10-30 recruiter visits

## Live Coding en Twitch/YouTube (Subestimado 2026)

**Por que funciono en 2025:**

- Viewers NO quieren codigo perfecto—quieren verTE pensar
- Error + debugging = mejor aprendizaje que curated code
- Comunidad se forma alrededor de consistency, no calidad

**Modelo minimo viable:**
- 1 stream/semana: 2h development actual en vivo
- Editable para YouTube clip despues
- Guardar como "portfolio evidence" (muestra skill + transparency)
