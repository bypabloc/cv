# Que Proyectos Mostrar

## 1. Open Source Contributions > Solo Side Projects

**Valor relativo (2025-2026):**

- **Open source:** Demuestra: colaboracion, revision de codigo, comunicacion, entendimiento de codebases grandes
- **Side projects:** Demuestra: iniciativa, ejecucion end-to-end, pero es tuyo solo = menos señal de trabajo en equipo

**Dato:** Contribuciones a open source visibles en tu GitHub generan 3x mas interview requests que side projects desconocidos.

## 2. SaaS One-Person Viables (2025-2026)

Por primera vez, un desarrollador SOLISTA puede construir SaaS lucrativo con:
- **AI tools** (Cursor, Claude Code) para desarrollo rapido
- **Supabase** (Postgres + auth + functions + storage)
- **Next.js + Vercel** (deployment trivial)
- **Stripe** (payments)

**Hallazgo Stripe 2024-2025:** 44% de SaaS rentables ahora son solo 1 persona. Muchas ganan $10K+/MRR sin empleados.

**Como mostrar en portfolio:**
- Featured section con monetizacion ($ semanal/mensual)
- Explicar arquitectura: "Built in X days using Claude Code + Supabase + Vercel"
- ROI/metrics: "1000 subscribers, $5K MRR, migrado desde monolith a serverless con Claude Code refactoring"

## 3. Hackathon Projects = Portfolio Gold

- **54% de recruiters** valoran hackatons mas que GPA perfecto
- Demuestra "self-driven problem solver" bajo presion
- Solana Cypherpunk 2025: 9,000 participantes de 150+ paises

**Como mostrar:**
```markdown
## Hackathons

### Solana Cypherpunk 2025
- **Role:** Full-stack engineer
- **Project:** Decentralized payment escrow (48h)
- **Tech:** Rust (smart contract) + Next.js + Phantom wallet integration
- **Outcome:** Built working prototype, learned Rust in 24h with Claude Code, top 50 finalist
- **GitHub:** [link]
```

## 4. Proyectos con IA Integration Destacados

**Portfolio favorita 2026:** Proyectos que muestren:

1. **RAG + LLM Integration** (Document search, customer support bot)
2. **Multi-agent workflows** (LangChain, CrewAI)
3. **Fine-tuning** o **prompt optimization** documentado
4. **MCP servers** personalizados

**Ejemplo destacable:**
- "Built legal document analyzer with RAG (LlamaIndex) + Claude, reduced search time 80%, handles 500+ doc corpus"
- **Por que destaca:** Muestra domain problem + AI solution + metrics

## 5. Projects That Solve Real Problems

Recruiters en 2026 aman:
- Algo que USAS vos mismo
- Algo con usuarios reales (aunque sean 50)
- Algo con metrica (tiempo ahorrado, dinero ganado, bugs reducidos)

EVITAR:
- "Todo-list app built with [hot-tech]"
- "Tutorial project" (salvo que añadas valor unico)
- Proyectos que no documentan impacto
