# Stack Recomendado y Checklist

## Tech Stack Recomendado 2026 (Demanda + Compensacion)

```
FRONTEND
├─ React 19+ / Next.js 16+
├─ TypeScript (strict mode)
├─ TailwindCSS v4 (utility-first)
├─ Zustand / Tanstack Query (state management)
└─ Testing: Vitest + Testing Library

BACKEND
├─ Node.js / Python 3.14 / Go 1.23+
├─ API framework: Express / FastAPI / Echo
├─ Database: PostgreSQL 18 (first choice)
├─ ORM/Query: Prisma / SQLAlchemy / sqlc
└─ Testing: pytest / Jest + Supertest

DEVOPS
├─ Docker (multi-stage builds)
├─ GitHub Actions (CI/CD)
├─ 1 cloud: AWS / GCP / Vercel (pick one, go deep)
└─ Monitoring: Sentry + structured logging

AI/ML
├─ LLM integration: OpenAI / Anthropic API
├─ RAG framework: LlamaIndex or LangChain
├─ Embeddings: OpenAI, Cohere, or local (Ollama)
└─ Vector DB: Supabase pgvector, Pinecone, Weaviate

TOOLS
├─ Code editor: VS Code + Cursor + Claude Code
├─ Package manager: pnpm (faster than npm)
├─ Git: GitHub (not GitLab or Gitea—employers know GitHub best)
└─ Docs: Markdown + Maybe Notion or Confluence for large projects
```

## Portfolio Checklist: ¿Estas Listo?

### Antes de Publicar

- [ ] **README principal explicita tech stack** (lenguajes, frameworks, porque cada uno)
- [ ] **6 repos pinneados**: Showcase + open source + monitized + tool + learning + recent
- [ ] **Commit messages Conventional Commits** (feat, fix, docs, refactor)
- [ ] **PRs con descripciones** (que cambio, por que, como probar)
- [ ] **Test coverage >= 80%** en archivos principales
- [ ] **Cada proyecto tiene demo en vivo** o video walkthrough

### Presencia Online

- [ ] **Twitter:** 5-10 posts tecnicos mensual
- [ ] **GitHub profile README:** Bio + current projects + contact
- [ ] **Dev.to o blog personal:** 1 articulo profundo trimestral
- [ ] **LinkedIn actualizado:** Job title, link a portfolio, lista de skills
- [ ] **(Opcional) YouTube/Twitch:** 1-2 vids de live coding si tienes tiempo

### Skill Development (3-6 Meses)

- [ ] **Completa 1 hackathon** o "ship in 48h" challenge
- [ ] **Contribuye 5+ PRs** a open source repo conocido
- [ ] **Build 1 SaaS side project** con monetizacion visible
- [ ] **RAG + LLM project** (Q&A bot, document analyzer)
- [ ] **Blog post detallado** sobre "how I built X"

### Documentation & Transparency

- [ ] **README documenta decisiones** (por que X sobre Y)
- [ ] **Explica AI usage** (si aplica—transparent workflow)
- [ ] **Architecture diagrams** para proyectos medianos
- [ ] **Metrics visible:** Time saved, users, $ generated, bugs reduced

### Antes de Entrevistas

- [ ] **Resume alineado** con GitHub (mismas projects)
- [ ] **Video portfolio walkthrough** (5-10 min) grabado
- [ ] **Be ready para:** "¿Como debuggearias X?" (process, no solucion)
- [ ] **Ejemplos de "code review"** (como ves calidad en otros PRs)
