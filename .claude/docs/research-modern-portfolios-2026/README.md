## Resumen ejecutivo

- **Portfolio web propio supera LinkedIn como canal primario**: 72% de profesionales creativos reportan que clientes y reclutadores evaluan portfolios primariamente via sitio web personal, no marketplaces ni redes sociales.
- **ATS evoluciono de matching literal a contextual**: adoption de IA en ATS paso de 26% (2024) a 43% (2025). Job title es el keyword mas critico (10.6x mas probabilidad de entrevista cuando esta visible).
- **GEO emerge como nueva capa de visibilidad**: SEO tradicional declinara 25% para 2026 y 50% para 2028. `llms.txt` + Schema.org Person/ProfilePage son la nueva base para que LLMs te citen.
- **Stack recomendado**: Astro 6.1 + Tailwind CSS v4 + Cloudflare Pages para portfolios estaticos (40% mas rapido que Next.js, bandwidth ilimitado, builds en segundos).
- **Dark mode + WCAG AA son obligatorios**: 82.7% de usuarios usan dark mode; EU Accessibility Act obligatorio desde Junio 2025, ADA deadline Abril 2026. Core Web Vitals: LCP < 2.0s (umbral nuevo Marzo 2026).
- **Personal branding 2026 = criterio + accion**, no visibilidad. Niche claro + voice autentico + accion demostrable (codigo, demos, papers) supera a "publica mas".

## Reglas criticas

- **SIEMPRE** documentar uso de IA con transparencia (no es tabu, es ventaja en 2026).
- **SIEMPRE** estructurar case studies como Problema -> Proceso -> Resultado con numeros concretos.
- **NUNCA** presentar solo portfolio web a reclutadores: workflow es CV ATS + link a portfolio + GitHub + LinkedIn.
- **NUNCA** usar tablas, multiples columnas o imagenes con texto critico en CV (rompe parsing ATS).
- **NUNCA** bloquear CCBot, GPTBot, Claude-Web en robots.txt (mata GEO).
