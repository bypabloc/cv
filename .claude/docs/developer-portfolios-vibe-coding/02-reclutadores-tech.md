# Que Buscan los Reclutadores Tech 2025-2026

## 1. AI Literacy como Skill Base

**Definicion 2026:** No es ser un experto en ML. Es saber cuando IA te ayuda, como dirigirla, y cuando desconfiar de su output.

**Componentes que evaluan:**

| Aspecto | ¿Que valoran? |
|---------|---------------|
| **Prompting** | Claridad en instrucciones, iteracion efectiva, context injection |
| **Critical evaluation** | Deteccion de hallucinations, "sniff tests" de output sospechoso |
| **Tool selection** | Saber cuando usar Claude Code vs Cursor vs async batch processing |
| **Domain expertise + IA** | Combinar knowledge del dominio con AI para evitar errores costosos |
| **Transparency** | Documentar que codigo fue IA-asistido vs hand-crafted |

**Dato critico:** 70% de employers estan usando **skills-based hiring** (2026), evaluando que puedes HACER, no donde estudiaste.

## 2. Señales de Contratacion Real

Las pruebas tecnicas estan evolucionando. No solo test algoritmos, sino:

- **Proceso visible:** Como debuggeas problemas (sin importar si cometes errores—importa como los resuelves)
- **Comunicacion escrita:** Commits claros, PRs con descripciones, issues bien articuladas
- **Decisiones tecnicas explicadas:** Por que elegiste X sobre Y
- **Colaboracion:** Como trabajas con IA y humanos

## 3. Diferencia Junior / Mid / Senior Post-IA

| Nivel | Cambio Clave | Skill Critical |
|-------|-------------|-----------------|
| **Junior** | 13% de codigo AI-generado vs 1/3 en seniors | Prompting + critical eval + aprender rapido |
| **Mid** | Propietario de features completas, no lineas | Arquitectura + trade-offs + ownership |
| **Senior** | 2.5x mas shipped code via IA, menos "escribir manual" | Juicio tecnico + mantener calidad global + leadership |

**Hallazgo 2025:** 54% de engineering leaders planean contratar MENOS juniors (gracias a IA), pero 42% reconocen que "en 10 años no tendremos nadie que haya aprendido nada" si no invertimos en junior pipeline.
