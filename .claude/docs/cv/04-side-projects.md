## 🟢 FastStruct

Una extensión de VS Code para visualizar y documentar rápidamente la
estructura de archivos de un proyecto. FastStruct ayuda a crear
documentación clara y bien formateada de la estructura de directorios,
incluido el contenido de los archivos cuando sea necesario.

**Motivación**

- Por ocio: aprender a hacer una extensión para VS Code.
- Simplificar un proceso manual que se hacía al interactuar con la IA
  (pasarle estructura de proyecto + contenido).
