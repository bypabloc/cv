## Repos Pinned (Max 6, Strategy Required)

| Tipo | Que Pinear | Por Que |
|------|-----------|---------|
| **Showcase** | Tu best technical project (live demo si es posible) | Recruiters ven esto primero |
| **Open Source** | Contribution a conocido repo (Rails, React, etc.) | Demuestra capacidad de trabajar en codebases grandes |
| **Monetizado** | Tu side SaaS con metrics (stars / downloads / users) | Demuestra ambicion + ejecucion |
| **Herramienta** | CLI tool, lib, o generator con documentacion clara | Demuestra empowerment de otros |
| **Learning** | Proyecto donde enseñas algo (tutorial, educational repo) | Demuestra comunicacion |
| **Recent** | Reciente completado (< 3 meses) | Señal de actividad = relevancia |

## Commit History Sigue Importando

**2026 insight:** Recruiters NO miran "green squares" (GitHub contributions chart), pero SI miran:

1. **Commit message clarity** (Conventional commits = +profesionalismo)
2. **PR quality** (Descripciones detalladas, bocetos de cambio, discusion)
3. **Release discipline** (Tags semver, CHANGELOG, notas de release)

Ejemplo de commit bueno:
```
feat(appointments): add SELECT FOR UPDATE SKIP LOCKED for double-booking prevention

- Implement atomic slot reservation with transaction.atomic decorator
- Add unit tests for concurrent slot contention scenarios
- Reduce race condition incidents 92% (measured in staging)

Fixes #245
```

## GitHub Stats That Matter (2026)

| Metrica | Señal Fuerte | Señal Debil |
|---------|--------------|------------|
| Estrellas | 100+ en open source propio | 0 o fake (copied projects) |
| PRs | 50+ en 1 año en repos ajenos | Ninguno (solo owner) |
| Issues | Contribuidor a ecosistema | 0 |
| Followers | 200+ = voz tecnica | 0 |
| Releases | Disciplina semver | Jamas taggeados |
