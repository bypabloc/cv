# Herramientas de IA: Claude Code vs Cursor vs Windsurf

## Comparativa de Mercado (Mayo 2026)

| Criterio | **Claude Code** | **Cursor** | **Windsurf** | **GitHub Copilot** |
|----------|-----------------|-----------|------------|-----|
| **Adopcion** | 18% workplace | 18% workplace | ~5% | 29% workplace |
| **Satisfaction (CSAT)** | 91% (HIGHEST) | 86% | 85% | 78% |
| **NPS** | 54 (HIGHEST) | 48 | 42 | 35 |
| **SWE-bench Verified** | 92.4% (Sonnet 5, Apr 2026) | 48% (Mar 2025) | ~60% | 55% |
| **Pricing** | Free (CLI) / pro tiers | $20/month | $15/month | $10-20/month |
| **Interface** | Terminal-only | VS Code fork | VS Code fork | Copilot chat |
| **Best for** | Complex refactoring, multi-file | Daily coding, inline edits | Privacy-first, free tier | Routine completion |
| **Context window** | 1M tokens | 200K | 200K | 256K |

## Recomendacion Profesional 2026

**Patron adoptado por seniors:** Cursor para trabajo diario ($20/mes) + Claude Code para tasks complejas (arquitectura, refactoring 10+ archivos) = $40/mes cubre "todo".

## Documentar el Stack en Portfolio

Si mencionas uso de IA, se especifico:

```markdown
## Tools & Workflow

**Development:** VS Code + Cursor (inline edits) + Claude Code (complex thinking)
**Problem-solving approach:**
- Cursor para autocomplete y small-scale edits (faster iteration)
- Claude Code para architectural decisions (multi-file refactoring) 
- Manual review de todo output (hallucination detection)

**Time saved:** ~30% en boilerplate, 0% en diseño de arquitectura (eso sigue siendo 100% humano)
```
