# Apendice: Checklist Rapida de Validacion

```
ESTRUCTURA CONTENIDO
[ ] Home hero comunica tu especialidad en 5 segundos
[ ] 3-5 case studies con estructura Problema -> Solucion -> Impacto
[ ] Cada proyecto tiene numeros concretos (% mejora, usuarios, ingresos)
[ ] Links funcionales a demos/repos (verificado 1x/mes)
[ ] Dark mode + Light mode ambos pulidos

TECNOLOGIA
[ ] Astro 6.1 + Tailwind CSS v4 (o Next.js si hay estado complejo)
[ ] Core Web Vitals 100/100 (Lighthouse)
[ ] LCP < 2.0s, INP < 200ms, CLS < 0.1
[ ] WCAG AA (axe DevTools, 0 errores)

VISIBILIDAD (SEO + GEO)
[ ] JSON-LD Person schema implementado
[ ] llms.txt creado en dominio raiz
[ ] robots.txt permite CCBot, GPTBot
[ ] Google Rich Results Test: pasa
[ ] Hosted en Cloudflare Pages (bandwidth ilimitado)

PERSONAL BRANDING
[ ] CV optimizado para ATS (single-column, job title visible)
[ ] GitHub README profesional, 4-6 repos pinned
[ ] LinkedIn perfil + 3 posts/semana (insights, no vanity)
[ ] Niche especifico (no "developer", sino especialidad)
[ ] IA documented en projects donde se use

MANTENIMIENTO
[ ] Portfolio actualizado "May 2026" (o fecha actual)
[ ] Links verificados (monthly)
[ ] Case studies actualizados cuando tengas nuevos proyectos
[ ] LinkedIn engagement monitoreado (semanal)
```
