## Resumen ejecutivo

- **Vibe coding** fue elegida Palabra del Año 2025 por Oxford English Dictionary. 92% de desarrolladores estadounidenses usan herramientas de IA daily y 41% del codigo global es AI-generado en 2026.
- El recruiting pivoto de "puede escribir codigo" hacia "puede orquestar IA, evaluar output criticamente y entregar features rapido". 70% de employers usan skills-based hiring.
- **Claude Code** lidera satisfaccion (91% CSAT, 54 NPS, 92.4% SWE-bench Verified) seguido de Cursor (1M+ DAU) y Windsurf (adquirido por Cognition AI por 10.2B USD).
- Para destacar en 2026 el portfolio debe combinar: 6 repos pinneados estrategicos, side SaaS monetizado, contribuciones open source visibles, presencia en Twitter/X, blog tecnico y documentacion transparente del uso de IA.
- Junior pipeline en riesgo (54% menos hiring planificado) pero seniors con IA fluida ganan 2.5x mas shipped code y mayor compensacion. AI Engineer crece 300% YoY mientras Prompt Engineer declino 60% en 2025.

## Reglas criticas

- SIEMPRE documentar uso de IA de forma transparente — ocultarlo o exagerarlo penaliza igual ante reclutadores.
- NUNCA listar "AI-generated codebase" como atributo positivo — señal de no poder mantener el codigo.
- SIEMPRE incluir metricas (usuarios, MRR, tiempo ahorrado, bugs reducidos) en proyectos del portfolio.
- NUNCA pinear repos sin demo en vivo o video walkthrough si pretendes destacar el proyecto.
